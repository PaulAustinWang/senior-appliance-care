# 樂齡家電守護

顧客網站：https://paulaustinwang.github.io/senior-appliance-care/

正式服務平台：https://senior-appliance-care-service.artfulkiwi33.chatgpt.site/

門市後台：https://senior-appliance-care-service.artfulkiwi33.chatgpt.site/staff

GitHub Pages 保留入口並導向具有後端的服務平台。門市登入後可建立師傅資料、安排來訪日期與時間；顧客可查看已確認的師傅、時段及門市聯絡資訊。安排包含額外 25 分鐘教學，並檢查時段衝突、語言與每日工時。

顧客換裝置時，以服務編號及原聯絡電話查詢。服務需求、偏好與排程存於正式資料庫；操作、保固及問題筆記仍保留個人備份功能。

本儲存庫不包含顧客資料、資料庫、管理密碼或私密設定。後端執行於 Sites / Cloudflare Workers，D1 提供持久資料儲存。完整後端來源另由 Sites 版本庫管理。
